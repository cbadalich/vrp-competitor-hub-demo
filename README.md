# VRp Competitor Hub (public demo)

A read-only demo of a competitive-intelligence monitor built as a course project
(Leeds, Fall 2026). Every value in it is quoted from the companies' own public
websites and checked word for word against the saved page.

- Market overview, Comparison, Competitor profiles and Insights show the data.
- How it works explains the pipeline; Discovery shows how new companies are found.
- The saved copies of the websites are not included; quote checks shown are the
  ones recorded when the data was built.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.
